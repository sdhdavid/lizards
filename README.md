# הלטאות של לביא

משחק דפדפן בעברית: לביא, ילד בן שמונה, אוסף לטאות ומגדל אותן בטרריום.

- **הטרריום:** מאכילים, שומרים על חום נעים, ממלאים מים, מנקים ומלטפים. הלטאות גדלות, מטילות ביצים, ולפעמים בורחות ומתחבאות בבית.
- **מסעות:** החצר של סבתא, חורש בכרמל, חולות ניצנה ומכתש רמון. מרימים מחבואים ותופסים לטאות לפני שהן בורחות.
- **המגדיר:** 11 מינים אמיתיים מישראל, עם עובדה על כל אחד.
- **חנות ומשימות:** אוכל, שדרוגים ומשימות קטנות שמזכות במטבעות.

## איך מריצים

פותחים את `index.html` בדפדפן. אין שלב בנייה ואין תלויות; הכול בקובץ אחד.
ההתקדמות נשמרת בדפדפן (localStorage).

במציאות, כל הזוחלים בטבע בישראל מוגנים בחוק. מתבוננים, מצלמים ומשאירים אותם בבית שלהם.
